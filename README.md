# Sharp Partial Identification and Safe Offline Policy Improvement with MNAR Rewards

This repository develops a theory-first offline reinforcement learning method for logs in which states, actions, and transitions are recorded but reward observation may depend on the latent reward itself. The implementation is tabular, deterministic under fixed seeds, CPU-only, and intended to make the identification and safety claims directly auditable.

## Main contributions

- Nonidentification of policy values and the optimal action under unrestricted reward-dependent missingness.
- Closed-form **sharp** binary-reward intervals under an odds-ratio sensitivity parameter `Gamma`, plus a finite-alphabet LP.
- Sharp candidate-versus-baseline improvement intervals and an exact shared-uncertainty cancellation identity.
- An occupancy-measure LP for maximizing worst-case improvement over a baseline.
- An exact ambiguity-regret characterization showing when uniformly safe deployment must abstain even with infinite data.
- One-sided exact confidence limits that remain valid after searching over a data-dependent policy class.
- A transition-estimation correction using simultaneous multinomial L1 radii.

## Empirical snapshot

All reported values are generated by `experiments/run_all.py` and checked into `results/`.

| Validation | Result |
|---|---:|
| Critical sensitivity in analytic bandit | `Gamma* = 2.25` |
| Direct cancellation certificate | `0.1314` |
| Separate-value certificate at low shared observation | `-0.8486` |
| Pointwise-then-select false rate, 100 null policies | `74.33%` |
| Simultaneous false rate, 100 null policies | `0.37%` |
| Direct safe mean improvement, 200 random MDPs | `0.0492 ± 0.0012` |
| Direct safe harmful-deployment rate | `0 / 200` |
| Maximum unsafe rate when assumed `Gamma` covers truth | `0%` |
| Maximum unsafe rate under under-specified `Gamma` | `91%` |
| Transition-adjusted false deployment, all tested sizes | `0%` |
| Transition-adjusted power at `n=1000` | `99.0%` |

These are controlled validations of theorem-predicted behavior, not claims of benchmark-scale deep-RL superiority.

## Reproduce

```bash
python -m pip install -e '.[dev]'
pytest
python experiments/run_all.py \
  --random-mdps 200 \
  --replicates 1000 \
  --post-selection-replicates 3000 \
  --gamma-mdps 100 \
  --workers 4
cd paper && bash build.sh
```

The complete experiment suite takes about 30 seconds on the reference five-vCPU environment and uses no GPU. See [`docs/REPRODUCIBILITY.md`](docs/REPRODUCIBILITY.md) for exact software, seeds, metrics, and output files.

## Repository layout

- `src/mnar_rl/`: identification, confidence, MDP, and robust-optimization utilities.
- `experiments/run_all.py`: all synthetic experiments and plotting code.
- `tests/`: unit tests for sharp endpoints, minimax formulas, LP validity, cancellation, and transition penalties.
- `results/`: exact CSV/JSON outputs used in the manuscript.
- `figures/`: generated standalone figures.
- `paper/`: manuscript, supplement, bibliography, and checklist.
- `docs/`: proof status, reproducibility details, and submission audit.

## Scope and assumptions

The formal guarantees require that the true reward-observation mechanism belongs to the analyst-specified `Gamma` sensitivity class. `Gamma` is not identified by the same MNAR observed law and should be reported as a sensitivity curve or calibrated from external knowledge. Rectangular reward ambiguity, finite state/action spaces, correctly logged missingness indicators, and independent trajectories are explicit assumptions of the current theory.
