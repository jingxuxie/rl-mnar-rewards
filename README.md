# Sharp Partial Identification and Safe Offline Policy Improvement with MNAR Rewards

This repository studies offline reinforcement learning when states, actions, and transitions are logged, but reward observation may depend on the latent reward itself. The project is deliberately theory-first: all reported experiments use exact tabular planning and run on a CPU-only laptop.

## Main contributions

- **Nonidentification:** without a restriction on reward-dependent recording, observationally equivalent logs can imply opposite optimal actions.
- **Sharp reward sets:** binary rewards admit closed-form identified intervals under an odds-ratio sensitivity parameter `Gamma`; finite reward alphabets reduce to small linear programs.
- **Contrastive geometry:** the sharp candidate-minus-baseline interval has width
  `sum_x |d_pi(x)-d_b(x)| (u_x-l_x)`, so uncertainty on shared occupancy cancels exactly.
- **Contrastive missingness budget:** the ambiguity width is bounded by a product of the sensitivity strength, local missingness, and candidate-baseline occupancy distance.
- **Exact policy optimization:** a linear program over finite-horizon occupancy measures maximizes worst-case improvement over a baseline.
- **Useful randomization:** a one-step construction shows that every deterministic policy can fail certification even though a randomized occupancy policy is safely improving.
- **Unavoidable abstention:** when the sharp improvement interval crosses zero, the exact minimax randomized and deterministic regrets are positive, and a uniformly safe selector must almost always retain the baseline.
- **Post-selection validity:** three one-sided exact binomial limits per reward cell yield one outer reward set valid simultaneously for the entire data-dependent policy search.
- **Finite-sample decomposition:** the deployment margin separates irreducible MNAR identification ambiguity, reward-estimation error, and transition-estimation error.

## Reproduce

```bash
python -m pip install -e '.[dev]'
pytest -q
python experiments/run_all.py \
  --random-mdps 200 \
  --replicates 1000 \
  --post-selection-replicates 3000 \
  --gamma-mdps 100 \
  --workers 4
cd paper && bash build.sh
```

The full reference experiment run uses no GPU and completes in under 30 seconds on the recorded five-vCPU environment. Fixed seeds and checked-in plotting summaries make every manuscript number reproducible.

## Current empirical snapshot

- Direct baseline-relative optimization has **zero harmful deployments** and mean improvement `0.0492` on 200 random MNAR MDPs; separate robust value bounds are safe but never deploy.
- Searching 100 null candidates after using fixed-policy intervals falsely certifies improvement in `74.3%` of trials, compared with `0.37%` for the simultaneous construction.
- In the identification-estimation phase experiment, more data gives near-unit power when the population robust margin is positive, but cannot rescue a comparison whose sharp population interval still crosses zero.
- At `Gamma=3`, a three-action example has negative robust improvement for every deterministic policy, while the occupancy LP finds a randomized policy with certificate `0.03`.
- The sensitivity-misspecification grid has zero unsafe deployments whenever the analyst's assumed `Gamma` covers the true mechanism; severe under-specification can be unsafe.

## Repository layout

- `src/mnar_rl/`: sharp bounds, tabular MDP utilities, simulation, and robust optimization.
- `experiments/run_all.py`: all experiments and figure generation.
- `tests/`: unit tests for sharpness identities, confidence mapping, minimax regret, transition penalties, and the occupancy LP.
- `paper/main.tex`: AAAI manuscript; non-reference content is automatically checked to end no later than page 7.
- `paper/supplement.tex`: complete proofs and additional experimental details.
- `paper/ReproducibilityChecklist.tex`: separately compiled AAAI checklist.
- `docs/PROOF_ROADMAP.md`: theorem audit and remaining research extensions.
- `docs/REPRODUCIBILITY.md`: environment, seeds, metrics, and commands.
- `results/`: checked-in manuscript summaries; full raw tables are regenerated by the experiment script.
